# Building the Voxy mod JAR

The repository includes one-click build entry points for all supported desktop platforms. All three use the checked-in Gradle wrapper, perform a clean build, and copy the newest installable remapped Fabric mod JAR into `dist/`.

## Requirements

- JDK 25 or newer (`java` must be available in `PATH`)
- Internet access on the first build so Gradle can download dependencies
- Git is recommended because Voxy embeds the current commit hash when available

The build scripts pass `-PincludeOtherArchs=true`, so the produced package keeps the additional native variants used by the multi-platform build rather than stripping them for a single development machine.

## Windows

Double-click:

```text
build-mod-windows.bat
```

Or run it from Command Prompt / PowerShell.

## Linux

Run:

```bash
./build-mod-linux.sh
```

If the executable bit was lost when the source tree was copied, use:

```bash
bash build-mod-linux.sh
```

## macOS

Double-click:

```text
build-mod-macos.command
```

You can also run it from Terminal:

```bash
./build-mod-macos.command
```

If macOS removes the executable bit while copying/extracting the repository, run `chmod +x build-mod-macos.command` once.

## Output

After a successful build, the installable mod JAR is copied to:

```text
dist/
```

The scripts ignore source/dev/javadoc JARs and select the newest installable JAR generated by Loom. Put that JAR in the Fabric `mods` directory together with Voxy's normal runtime dependencies.
